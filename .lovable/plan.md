# Sahala Shana VK Portfolio

## Goal
Build a premium, responsive portfolio that presents Sahala first as a B.Tech Information Technology student and future technology professional: a software developer focused on attractive, user-friendly digital experiences. UI/UX remains a supporting advantage, never the primary identity. Use the selected grid-led direction as the foundation, refined into a modern creative light/dark experience with disciplined columns, precise typography, subtle gradients, restrained accents, and calm motion.

## What I’ll build
- Replace the placeholder home page with one polished, long-form portfolio experience.
- Add sticky desktop navigation, a mobile menu, active section cues, resume action, and light/dark theme toggle.
- Build a strong opening section with Sahala’s name, configurable current role, core statement, three actions, social links, and a deliberately neutral profile-photo placeholder.
- Include every requested section in this hierarchy: Software/Technology identity, Projects, Technical Skills, Experience, Education, Professional Development, UI/UX & Creative Work, Certifications, Volunteering, Personal Interests, Resume, and Contact.
- Give HostelHub and Gramika prominent editorial project layouts and strong visual importance. Project detail views will use only the facts provided: titles, broad purpose, Flutter/Firebase technology, stated multi-role context, and placeholders for unavailable details and screenshots.
- Keep creative work visually understated and clearly secondary to engineering.
- Add an accessible contact form that opens a prepared email, plus working email, phone, GitHub, LinkedIn, YouTube, and Instagram links.
- Add resume view/download placeholders with clear states until a resume file is supplied.

## Content architecture
- Create a centralized portfolio data module containing identity, career positioning, links, navigation, focus areas, categorized skills, projects, experience, education, development activities, leadership, interests, and contact details.
- Keep the role/subtitle and status fields isolated so “B.Tech Information Technology Student” can later become “Software Engineer” without changing page code.
- Use explicit placeholder fields for the profile photo, project screenshots, internship certificate, Canva profile, and resume.
- Model lists and timeline entries so future internships, jobs, projects, certifications, AI/ML work, and post-2027 experience can be added without redesigning the page.
- Treat AI/ML, cloud, cybersecurity, React, and .NET only as learning or exploring topics, never as expert skills.
- Do not add unprovided employers, awards, statistics, project claims, screenshots, certificate details, or achievements.

## Visual and interaction details
- Adapt the chosen strict 12-column composition and typography into semantic light/dark theme tokens while preserving its premium editorial character.
- Support light and dark themes with saved preference and system-theme fallback.
- Use Space Grotesk for display text and Inter for body copy.
- Add restrained entrance reveals, section numbering, precise rules, and focused hover/focus treatments while respecting reduced-motion settings.
- Ensure the layout works across phone, tablet, and desktop sizes without clipped navigation, text, or controls.
- Avoid neon, hacker motifs, generic developer imagery, excessive glass effects, and excessive animation.
