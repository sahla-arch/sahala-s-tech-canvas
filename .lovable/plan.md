# Sahala Shana VK Portfolio

## Goal
Build a premium, responsive portfolio that presents Sahala first as an emerging software and technology professional, with UI/UX as a supporting advantage. Follow the selected Swiss Editorial Grid direction: disciplined columns, warm paper surfaces, near-black typography, restrained red accents, compact labels, and subtle motion.

## What I’ll build
- Replace the placeholder home page with one polished, long-form portfolio experience.
- Add sticky desktop navigation, a mobile menu, active section cues, resume action, and light/dark theme toggle.
- Build a strong opening section with Sahala’s name, configurable current role, core statement, three actions, social links, and a deliberately neutral profile-photo placeholder.
- Include every requested section: About, Focus Areas, Skills, Featured Projects, Web Experiments, Experience, Design, Certifications, Education, Workshops, Leadership, Beyond Technology, Resume, and Contact.
- Give HostelHub and Gramika prominent editorial project layouts with interactive detail dialogs covering problem, solution, features, technology, and screenshot placeholders.
- Keep creative work visually understated and clearly secondary to engineering.
- Add an accessible contact form that opens a prepared email, plus working email, phone, GitHub, LinkedIn, YouTube, and Instagram links.
- Add resume view/download placeholders with clear states until a resume file is supplied.

## Content architecture
- Create a centralized portfolio data module containing identity, role, links, navigation, focus areas, categorized skills, projects, experience, education, development activities, leadership, interests, and contact details.
- Keep the role/subtitle and status fields isolated so “B.Tech Information Technology Student” can later become “Software Engineer” without changing page code.
- Use explicit placeholder fields for the profile photo, project screenshots, internship certificate, Canva profile, and resume.

## Visual and interaction details
- Port the chosen strict 12-column composition and typography into the project’s semantic theme tokens.
- Support light and dark themes with saved preference and system-theme fallback.
- Use Space Grotesk for display text and Inter for body copy.
- Add restrained entrance reveals, section numbering, precise rules, and focused hover/focus treatments while respecting reduced-motion settings.
- Ensure the layout works across phone, tablet, and desktop sizes without clipped navigation, text, or controls.

## Validation
- Confirm the app builds without errors.
- Check the live page at desktop and mobile widths.
- Verify menu, theme toggle, project dialogs, contact action, external links, and section navigation.
- Check metadata, heading structure, accessible labels, keyboard focus, and responsive text wrapping.
